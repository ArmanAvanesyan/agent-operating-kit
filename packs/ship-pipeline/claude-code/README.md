# Ship Pipeline compatibility plugin

`/ship-pr` routes to AOK's preservation-aware repository-delivery workflow.
Start with `aok delivery doctor --json`, then read the canonical issue-to-PR and
PR-convergence guides. Rendered bundles include the complete support tree.
Preserve unrelated work, discover project gates and bind independent review to
the current snapshot. Push, PR creation, merge and cleanup each require explicit
user authority. Green checks do not supply that authority. No assumed project
gates, blanket staging or unconditional merge/deletion is included.

`/fix-ci` and the CI fixer role remain complementary diagnosis guidance. They do
not bypass preservation or turn agent review into submitted GitHub approval.
See AOK's `docs/repository-delivery.md`.
